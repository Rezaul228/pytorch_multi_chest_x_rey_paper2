1. MODEL ARCHITECTURE OVERVIEW
================================================================================

The multimodal chest X-ray retrieval system implements a dual-branch architecture
designed for cross-modal learning between medical images and clinical text reports.
The model achieves state-of-the-art performance with 12.9M parameters (49.24 MB).

1.1 Core Components
-------------------
• Image Encoder: Custom CNN architecture with 5 convolutional layers
• Text Encoder: LSTM-based sequence processing with embedding layer
• Hierarchical Co-Attention: 2-layer cross-modal attention mechanism
• Dual Branch Architecture: Synergy and Difference learning pathways
• Contrastive Loss: Temperature-scaled similarity optimization

1.2 Architecture Flow Diagram
-----------------------------
Input Images (224x224x3) ──┐
                           │
                           ├─► Image Encoder ──┐
                           │   (Custom CNN)    │
                           │                   │
Input Text (64 tokens) ────┤                   ├─► Co-Attention ──► Dual Branch
                           │                   │   Layers (2x)      Processing
                           ├─► Text Encoder ───┘
                           │   (LSTM)
                           │
Vocabulary: 1968 tokens ───┘

1.3 Key Specifications
----------------------
• Embedding Dimension: 256
• Attention Heads: 8
• Feed-forward Dimension: 1024 (4x embed_dim)
• Co-attention Layers: 2 per branch
• Maximum Text Length: 64 tokens
• Image Resolution: 224×224×3
• Local + Global Attention: Hierarchical co-attention with learnable gates

3. HIERARCHICAL CO-ATTENTION MECHANISM
================================================================================

3.1 Multi-Head Attention Architecture
-------------------------------------
The hierarchical co-attention employs 8 attention heads across 2 layers per branch,
with BOTH local and global attention mechanisms and learnable gates.

Layer Structure:
```
HierarchicalCoAttention {
    // Local Cross-Attention
    cross_attention1: MultiheadAttention(embed_dim=256, num_heads=8)
    cross_attention2: MultiheadAttention(embed_dim=256, num_heads=8)
    
    // Global Cross-Attention  
    global_cross_attention1: MultiheadAttention(embed_dim=256, num_heads=8)
    global_cross_attention2: MultiheadAttention(embed_dim=256, num_heads=8)
    
    // Normalization layers (8 total)
    norm1, norm2, norm3, norm4: LayerNorm(256)
    global_norm1, global_norm2, global_norm3, global_norm4: LayerNorm(256)
    
    // Feed-forward networks (4 total)
    ffn1, ffn2: Linear(256 → 1024 → 256)
    global_ffn1, global_ffn2: Linear(256 → 1024 → 256)
    
    // Learnable gates (4 total)
    local_image_gate, local_text_gate: Parameter(1, 1, 256)
    global_image_gate, global_text_gate: Parameter(1, 1, 256)
}
```

3.2 Attention Computation Flow
------------------------------
Given image features I ∈ R^(B×196×256) and text features T ∈ R^(B×64×256):

Step 1: Local Image-to-Text Attention
    Q = I, K = T, V = T
    Attention_I2T = MultiHead(Q, K, V)
    Gated_I = sigmoid(local_image_gate) * Attention_I2T + (1-sigmoid(local_image_gate)) * I
    I' = LayerNorm(I + Gated_I)
    I' = LayerNorm(I' + FFN(I'))

Step 2: Local Text-to-Image Attention  
    Q = T, K = I', V = I'
    Attention_T2I = MultiHead(Q, K, V)
    Gated_T = sigmoid(local_text_gate) * Attention_T2I + (1-sigmoid(local_text_gate)) * T
    T' = LayerNorm(T + Gated_T)
    T' = LayerNorm(T' + FFN(T'))

Step 3: Global Attention Processing
    Global_I = mean(I', dim=1)  # (B, 1, 256)
    Global_T = mean(T', dim=1)  # (B, 1, 256)
    
    Global_I_attended = MultiHead(Global_I, T', T')
    Global_T_attended = MultiHead(Global_T, I', I')
    
    [Apply gates and normalization similar to local attention]

Step 4: Combine Local and Global Features
    I_final = I' + Global_I.expand_to_match(I')
    T_final = T' + Global_T.expand_to_match(T')

4. DUAL BRANCH PROCESSING
================================================================================

4.1 Synergy Branch Architecture
-------------------------------
The synergy branch learns complementary cross-modal representations by
emphasizing shared semantic information between images and text.

Processing Flow:
Image Tokens (B,196,256) ──┐
                           ├─► Co-Attention ──► Global Pool ──► Projection ──► Synergy Embedding (256)
Text Tokens (B,64,256) ────┘    Layers (2x)     (mean)        + LayerNorm

4.2 Difference Branch Architecture
----------------------------------
The difference branch has identical architecture to synergy branch but with
separate parameters, allowing it to learn different cross-modal relationships.

Processing Flow:
Image Tokens (B,196,256) ──┐
                           ├─► Co-Attention ──► Global Pool ──► Projection ──► Difference Embedding (256)
Text Tokens (B,64,256) ────┘    Layers (2x)     (mean)        + LayerNorm

4.3 Final Embedding Combination
-------------------------------
The final embeddings are computed by averaging both branches:

```python
final_image_emb = F.normalize((synergy_img_emb + diff_img_emb) / 2, p=2, dim=-1)
final_text_emb = F.normalize((synergy_txt_emb + diff_txt_emb) / 2, p=2, dim=-1)
```

5. LOSS FUNCTION ANALYSIS
================================================================================

5.1 Contrastive Loss Formulation
--------------------------------
The model employs temperature-scaled contrastive learning with τ = 0.07:

L_contrastive = -log(exp(sim(i,t)/τ) / Σ_j exp(sim(i,t_j)/τ))

Where:
• sim(i,t) = cosine similarity between image i and text t
• τ = temperature parameter (0.07)
• Normalization over all text samples in batch

5.2 Similarity Computation
--------------------------
Given embeddings e_img ∈ R^256 and e_text ∈ R^256:

Cosine Similarity:
sim(e_img, e_text) = (e_img · e_text) / (||e_img|| × ||e_text||)

Example Calculation:
e_img = [0.2, 0.5, -0.3, 0.1]
e_text = [0.3, 0.4, -0.2, 0.2]
dot_product = 0.2×0.3 + 0.5×0.4 + (-0.3)×(-0.2) + 0.1×0.2 = 0.34
||e_img|| = 0.583, ||e_text|| = 0.583
sim = 0.34 / (0.583 × 0.583) = 1.000

7.1 Model Architecture Implementation
------------------------------------
Framework: PyTorch 2.4.1
Key Dependencies:
• torch.nn.MultiheadAttention for co-attention layers
• Custom CNN architecture for image encoding (not ResNet-50)
• torch.nn.LSTM for text sequence processing

Custom Image Encoder Architecture:
```python
class ImageEncoder(nn.Module):
    def __init__(self, embed_dim=256):
        self.conv_layers = nn.Sequential(
            nn.Conv2d(3, 32, 3, stride=2, padding=1),    # 224→112
            nn.ReLU(),
            nn.Conv2d(32, 64, 3, stride=2, padding=1),   # 112→56
            nn.ReLU(),
            nn.Conv2d(64, 128, 3, stride=2, padding=1),  # 56→28
            nn.ReLU(),
            nn.Conv2d(128, 256, 3, stride=2, padding=1), # 28→14
            nn.ReLU(),
            nn.Conv2d(256, embed_dim, 3, stride=1, padding=1), # 14→14
        )
        # NOTE: FC layers defined but NOT used in forward pass
        self.fc_layers = nn.Sequential(
            nn.Linear(512 * 3 * 3, 1024),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(1024, embed_dim)
        )
    
    def forward(self, x):
        x = self.conv_layers(x)  # Only CNN layers used
        # Reshape to (batch_size, h*w, embed_dim) for attention
        return x.permute(0, 2, 3, 1).reshape(batch_size, h*w, -1)
```

Model Definition Structure:
```python
class MultimodalFusion(nn.Module):
    def __init__(self, vocab_size=1968, embed_dim=256, num_heads=8, num_layers=2):
        self.image_encoder = ImageEncoder(embed_dim)
        self.text_encoder = TextEncoder(vocab_size, embed_dim)
        self.synergy_branch = BranchEncoder(embed_dim, num_heads, num_layers)
        self.difference_branch = BranchEncoder(embed_dim, num_heads, num_layers)
```
